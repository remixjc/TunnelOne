# 隧行 TunnelOne · macOS 客户端设计

目标：一个软件完成 WireGuard 连接，并按每个隧道的开关决定是否启用代理。此文档与交互原型描述拟开发产品；不代表客户端已经开发完成。

## 默认使用流程

1. 首次使用：导入 WireGuard 的 `.conf` / `.zip`，允许系统 VPN 授权。
2. 若需要代理：导入 Clash / Mihomo 兼容配置，开启隧道的“连接时带入代理”。
3. 日常只需点击“连接隧道”，或在菜单栏选择隧道。
4. 按需连接同样遵循该隧道的代理开关。

推荐使用内置代理引擎，实现真正的单应用使用；同时保留“本机代理”兼容模式，可自动打开已有 Clash Party。兼容模式属于一个入口控制两个进程，界面应清楚区分。

## 界面结构

- 左栏：隧道列表、导入、导出全部、代理配置、连接日志、设置。
- 隧道概览：连接状态、连接/断开、代理开关、配置来源、失败策略、基础网络信息、握手与收发统计。
- 隧道配置：接口、密钥、地址、DNS、监听端口、MTU、多个对端、公钥、预共享密钥、Endpoint、AllowedIPs、持续保活；支持表单与原始配置文本编辑。
- 按需连接：Wi-Fi、以太网、所有 SSID / 包含指定 SSID / 排除指定 SSID。
- 代理配置：内置配置、规则/全局/直连模式、节点选择、订阅导入与更新；本机代理模式提供协议、地址、端口和自动启动现有客户端开关。
- 日志：隧道、代理、恢复事件，筛选与脱敏导出。
- 设置：登录启动、菜单栏、关闭窗口后运行、更新、授权状态与导出。

WireGuard 功能范围以官方 macOS 客户端为基准：隧道创建、导入、复制、编辑、启停、删除；单个/全部导出；多对端；按需连接；状态、握手、流量；菜单栏与日志。正式开发应逐项对照官方目标版本验收。WireGuard 配置文件与应用附加偏好分开存储，标准 `.conf` 保持可移植性。不把其他平台 `wg-quick` 的任意 PostUp/PostDown shell 脚本执行作为 macOS 客户端功能承诺。

## 开关的精确定义

“连接时带入代理”为每隧道独立偏好。新导入隧道默认关闭；示范隧道默认打开以便体验。

- 关闭：只应用原 WireGuard 配置，不启动内置代理，不覆盖已有系统代理。若用户原本已启用其他系统代理，它仍可能继续生效。
- 开启：准备所选代理服务；建立 WireGuard 隧道并确认握手；为该隧道应用代理；核验生效设置与实际访问。
- 运行中切换：选择“立即应用”或“下次连接生效”，避免开关状态与当前连接状态混淆。
- 断开：恢复连接前的代理状态，仅停止本次由隧行启动且由隧行管理的代理服务。

产品中的“带入代理”限定为 HTTP/HTTPS/SOCKS 系统代理。它不等同于所有进程和 UDP 均经过规则代理。若将来提供全应用代理，需另行设计数据包层分流，不能把一个系统代理开关描述为全流量接管。

## 连接与恢复状态

未连接 → 建立隧道 → 确认握手 → 准备代理 → 应用配置 → 验证网络 → 已连接。

代理关闭时跳过代理阶段。系统首次授权在正式建立连接前完成。握手超时属于隧道失败；端口不可达、配置错误、代理节点访问失败属于代理失败，日志应分别记录。

默认代理失败策略：断开本次隧道并恢复原配置。可选策略：保留 WireGuard，以明显状态提示代理未启用。

网络切换、休眠唤醒或按需重连后，重新确认网络会话及代理。不能依赖固定 `utun4` 或固定动态服务 ID；不能将 Connected 直接视为握手或上网成功。

“国内直连 / 国外代理”是当前需求对应的检查方案。正式产品应允许配置检查目标，避免将示例网站不可达误判为所有隧道失效；纯内网隧道使用其自身的握手或内网检查策略。

## macOS 实现方向

界面采用 SwiftUI/AppKit，隧道使用 Network Extension / WireGuard 的隧道实现。优先通过隧道网络设置中的代理配置与连接生命周期共同应用；当前脚本对动态配置库的修补只作为已验证的问题线索，不应直接成为产品的长期架构。

首次系统授权后，日常连接不应反复弹出终端 sudo 密码。发布需完成网络扩展权限、签名、分发方式以及所选代理引擎的许可审查，这些属于开发交付条件，原型没有实现。

WireGuard 私钥与预共享密钥使用系统钥匙串。日志与诊断默认隐藏密钥和订阅地址。导出 WireGuard 配置前明确提示包含私钥。保留代理所有权与连接前快照；若连接期间用户手动切换到其他代理，不盲目覆盖用户的新设置。

若代理引擎与隧道同进程或跨进程运行，需在正式开发中验证监听端口可达性、节点出站沿 WireGuard 的路径、DNS 引导、IPv6、重连及崩溃恢复；原型中的连通和时延为模拟值。

## 原型可体验范围

正常连接、关闭代理后连接、运行时立即切换、代理失败回滚、保留隧道、握手超时、首次授权、模拟网络变化、按需连接、代理来源与节点切换、多对端编辑、导入样本、配置预览与复制、菜单栏操作、日志。

所有连接和授权均为模拟，不改变电脑网络、不读取真实私钥、不请求订阅。导入文件用样本代替系统文件选择器；导出用可复制的演示文本代替真实 `.zip` 写盘。
