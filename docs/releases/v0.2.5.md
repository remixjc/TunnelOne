# TunnelOne v0.2.5 · Direct Probe Proxy Bypass · Signed Beta

修正 v0.2.4 实机检查中发现的代理与接口冲突：旧 through-tunnel API 仍会采用系统 Clash 代理，随后因本机回环接口不满足 WireGuard 接口绑定而超时，不能宣称其已经绕过代理。

- macOS 15+ 使用 `NWConnection` 和 `NWParameters.tls`，绑定本次 provider 的 `virtualInterface`，明确设置 `preferNoProxies = true`。
- 继续用百度域名进行 DNS / TCP / TLS / HTTP 检查，保留默认证书验证、有界响应头、取消和超时。Google 检查继续通过 Clash，任一失败仍自动回滚本次隧道。
- macOS 13/14 保留旧兼容 API，尚未通过实际联网验收；代理冲突仍会导致检查失败并回滚。
- 新增 TLS 参数回归，确认接口绑定、代理绕过和 TLS 同时生效。版本 **0.2.5（build 9）**。

安装前断开隧道并退出旧应用，将签名包中的 TunnelOne 放入 `/Applications`，按系统提示更新网络扩展。本版继续保持 Beta。
