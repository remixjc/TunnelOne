# TunnelOne v0.2.1 · Prototype UI & Clash Safety Startup Beta

本版将交互原型的主界面接入真实 macOS 客户端，并为外部 Clash Party 增加安全启动检查和失败回滚。

- 主窗口采用原型的侧栏、隧道列表、概览 / 隧道配置 / 按需连接标签页、代理开关、日志和设置布局。应用内 WebKit 页面通过原生桥接操作真实隧道，显示实际状态、握手、流量和检查报告。
- 默认使用已有 Clash Party 的 `127.0.0.1:7890`，无需另行导入代理 YAML。节点、规则和订阅继续由 Clash Party 管理；已有内置 Mihomo 配置保留。
- 开启「连接时带入代理」后，检查 Clash 系统代理、TUN、规则模式和端口；建立 WireGuard 后确认实际接口与 IPv4 主路由，按需同步临时隧道服务代理，再并行检查百度直连和 Google 代理访问。
- 检查失败时停止本次 WireGuard 连接，保留原有 Clash 代理，并在界面报告实际失败及回滚结果。新扩展未就绪时阻止外部代理连接，避免使用旧版启动流程。
- 应用和系统扩展版本升级为 **0.2.1（build 5）**；增加安全启动、报告隔离和客户端 UI 自动化检查。

## 安装与升级

下载 `TunnelOne-0.2.1-macOS-universal-signed.dmg` 或 `-signed.zip`，退出旧应用，将新版放入 `/Applications`，启动后按 macOS 提示允许安装 / 更新网络扩展。升级前请断开隧道并备份配置。新扩展未就绪时，使用「安装 / 允许网络扩展」并完成系统授权。

使用代理前，Clash Party 需保持：**系统代理开启、TUN 关闭、规则模式、混合端口 7890**。该流程要求本次 WireGuard 接管 IPv4 主路由；仅连接内网时可关闭「连接时带入代理」。修改开关前需断开隧道并关闭按需连接。

`-signed` 安装包仅在 Developer ID 签名检查、Apple 公证及 staple 验证成功后发布。支持 macOS 13+、Apple Silicon 和 Intel。

## 验证状态

22 项 Swift 测试、Go 测试、客户端 UI 和官网交互检查已通过。签名与公证验证分发要求；本次新安全启动流程仍待真实设备联网、失败回滚、休眠恢复及多用户验收，继续以 **Beta** 发布。v0.2.0 的历史联网记录不代替本版验收。
