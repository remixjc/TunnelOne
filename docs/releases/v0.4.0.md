# TunnelOne v0.4.0 · macOS + Windows

首次增加 Windows 原生客户端，继续保留 macOS System Extension 与自动沿用系统代理方案。

- Windows 10 2004+ / Windows 11，x64 / ARM64：原生中文窗口、托盘、配置新建/编辑、`.conf` / ZIP 导入、标准导出、启停和删除。
- 使用官方 WireGuard 1.1.1 隧道服务与驱动。安装包内含经过 SHA-256 和 WireGuard LLC 签名验证的官方 MSI，以及 .NET 10 自包含运行时。
- 用户配置使用当前用户 DPAPI；运行时使用机器 DPAPI 与 SYSTEM / 管理员专属 ACL，不将明文密钥落盘到服务配置。
- 每隧道系统代理检查，连接前后验证，代理设置变化后重新验证，失败回滚本次服务。Windows 沿用现有用户代理，不修改全局设置。
- 分别显示服务、握手、真实收发统计；正常退出断开，启动时清理本账户遗留服务。
- GitHub Actions 自动构建两个 Windows 架构，执行模型/加密/故障回滚测试、真实隔离服务测试和原生窗口渲染；产出安装 EXE、便携 ZIP、SHA-256。Tag 等待所有平台成功再统一发布。
- 官网新增 macOS / Windows 下载与安装说明，README 增加平台差异、构建方式和验收范围。

Windows 当前为 **Preview**。未配置 Windows 代码签名证书时，TunnelOne EXE 与安装程序未签名；官方 WireGuard MSI 单独签名。macOS 的 Signed Beta 标记仅适用于 macOS。可选 Windows 签名 secrets 见 [Windows 指南](../windows.md)。

Windows 的 ARM64 实机、真实远端 VPN 握手、具体代理客户端、网络切换和休眠恢复尚未完成验收。自动化隔离服务测试不代表已验证真实 VPN 上网。macOS 行为保持 v0.3.0 的实现，版本升级至 0.4.0 / build 11。

下载文件：`TunnelOne-0.4.0-windows-{x64,arm64}-setup.exe`、对应 `-portable.zip`、`SHA256SUMS-Windows-{x64,arm64}.txt`；macOS 继续提供 universal ZIP / DMG 和源码包。
