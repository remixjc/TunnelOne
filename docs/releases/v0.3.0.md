# TunnelOne v0.3.0 · System Proxy Inheritance · Signed Beta

TunnelOne 现在自动沿用用户已启用的 macOS 系统代理，兼容标准系统代理客户端，不再绑定 Clash Party。

- 连接时不打开代理软件、不读取客户端私有配置、不要求 7890 或所有协议相同端口。
- 保留 HTTP、HTTPS、SOCKS、PAC 和绕过规则。连接前验证快照，Connected 后同步本次隧道临时代理，并按系统实际生效规则验证访问。
- 没有系统代理时仅连接 WireGuard，明确显示“未启用系统代理”。仅内网 WireGuard 不再强制接管公网路由。
- 连接期间跟随来源网络服务的代理变化；不把自身配置作为来源。停止时清理本次隧道，不覆盖用户最新物理网络代理。
- 新隧道默认自动沿用系统代理；旧隧道保留开关与历史内置设置。版本 **0.3.0（build 10）**。

范围：系统代理模式；不保证仅 TUN / 其他 VPN、WPAD、额外认证代理或忽略系统代理的应用自动兼容。代理节点出口仍受客户端设置与 AllowedIPs 影响。macOS 13/14 与各客户端逐项实测仍待完成。

自动化验证覆盖真实本地 HTTP / SOCKS / PAC 请求、绕过规则、独立端口、无代理、Connected 等待、取消、临时服务归属和失败处理；发布包含通用构建、Swift / Go、客户端 UI、沙盒 WKWebView、签名与 Apple 公证。

签名包实机验收结果将在安装验证后补充。
