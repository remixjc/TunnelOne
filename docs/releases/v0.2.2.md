# TunnelOne v0.2.2 · Blank Window Fix · Signed Beta

修复 v0.2.1 启动后主窗口空白的问题。建议已安装 v0.2.1 的用户升级本版。

- 为主应用补齐 `com.apple.security.network.client` 沙盒权限，使 WebKit 内容与网络辅助进程能正常启动。本地页面及 UI 资源保持随应用打包，页面导航仍限定在应用内首页，CSP 保持禁止网络请求。
- 页面文件缺失、脚本启动失败、加载失败 / 超时或 WebKit 内容进程退出时，显示原生错误提示与「重新加载」按钮，避免停留在空白窗口。
- 新增运行生产界面容器的原生沙盒回归测试，覆盖 CSS / 图标加载、数据渲染、原生消息桥、截图、崩溃提示与重新加载，以及资源缺失提示。签名包检查同时核验 WebKit 所需权限。
- 版本升级为 **0.2.2（build 6）**，保留 v0.2.1 的原型 UI 和 Clash 安全启动流程。

## 下载与升级

下载 `TunnelOne-0.2.2-macOS-universal-signed.dmg` 或 `-signed.zip`。退出旧应用，将新版放入 `/Applications`，打开后按 macOS 提示允许更新网络扩展。升级前请断开隧道并备份配置。

支持 macOS 13+、Apple Silicon 和 Intel。签名安装包在 Developer ID 验证、Apple 公证及 staple 验证成功后发布。

本次已复现缺少权限时的 WebKit 进程崩溃，并验证补齐权限后真实沙盒 WKWebView 能正常显示原型界面。新安全启动流程的真实联网、失败回滚、休眠及多用户验收仍需继续，保持 **Beta**。验收详情见 [docs/acceptance.md](https://github.com/remixjc/TunnelOne/blob/v0.2.2/docs/acceptance.md)。
