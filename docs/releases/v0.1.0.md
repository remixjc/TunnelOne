# TunnelOne v0.1.0 · Developer Preview

首个开源开发预览，包含实际原生客户端源码、项目官网与自动构建发布。

- 基于官方 WireGuard macOS 客户端，保留标准隧道管理功能。
- 每隧道独立的「连接时带入代理」设置。
- 内置 Mihomo，或连接已经运行的 HTTP / mixed 代理。
- 扩展内管理代理启停、端口检查、失败回滚。
- Apple Silicon + Intel universal ZIP / DMG。
- 响应式官网、交互原型、GitHub Pages 与 tag 发布。

**请先阅读：** 这是未签名开发构建，不是可直接用于日常联网的正式 VPN 版本。真实连接需要开发签名、匹配的 Network Extension profiles 与运行验收。当前 Packet Tunnel App Extension 结构不能仅靠 Developer ID 公证转换成 GitHub 正式直发版；该路线需要 System Extension 适配。

代理监听检查不代表网站可达，当前也未完成签名后的真实联网验收。详见仓库 `docs/signing.md` 与 `docs/acceptance.md`。

下载中提供 SHA-256 文件，以及包含 Mihomo、WireGuard 依赖的对应源码归档。无需关闭系统安全保护来运行此预览。
