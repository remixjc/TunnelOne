TunnelOne — UNSIGNED DEVELOPER PREVIEW

This is an unsigned universal macOS 13+ development build.
It contains a System Extension, which cannot be activated without valid
Apple signing, provisioning profiles and notarization. This artifact is not
a working VPN installation package. Use a notarized -signed release to test VPN.

Do not disable SIP, Gatekeeper or signature checks to install this preview.
See README.md and docs/signing.md for the supported distribution process.
