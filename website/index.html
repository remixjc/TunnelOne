GOOD TO KNOW

开始前，
你可能想知道。

现在可以直接安装后日常使用吗？+

v0.4.0 提供 macOS Signed Beta 和 Windows Preview。macOS 请选择 signed 安装包并允许网络扩展。Windows 提供 x64 / ARM64 安装 EXE 与自包含便携 ZIP，默认未签名；官方 WireGuard MSI 单独签名。Windows 真实远端 VPN、代理组合、ARM64 实机与休眠恢复尚未验收，当前测试范围见仓库文档。

可以使用其他代理客户端吗？+

可以使用提供标准系统代理的客户端。代理服务需要已运行，TunnelOne 不启动指定软件。Windows 沿用当前用户系统规则，连接前后验证 HTTPS，并检查设置变化；PAC 和绕过规则可能选择直连。仅 SOCKS、TUN、WPAD 或额外认证代理的兼容性需单独验证。

“带入代理”会代理所有应用吗？+

只影响遵循系统代理的应用。macOS 将代理设置同步到本次隧道；Windows 保留用户现有系统代理。忽略系统代理的程序、UDP 和游戏流量不在这一开关的保证范围内；WireGuard 路由仍由 AllowedIPs 决定。

我的私钥和节点配置在哪里？+

macOS 私钥由系统钥匙串存储，历史代理 YAML 位于本机 App Group 容器。Windows 用户配置使用 DPAPI 加密，服务配置另以机器 DPAPI 与管理员 / SYSTEM 权限保护，断开时清理。项目没有账户或遥测服务；导出的标准 .conf 包含明文私钥。

已经发布的原型等同于客户端吗？+

原型用于体验 macOS 设计方向，全部连接与数据都是模拟。实际 macOS 客户端采用 AppKit 与本地 WebKit；Windows 使用原生 .NET 桌面窗口。各平台实现范围和验收清单以仓库文档为准。
