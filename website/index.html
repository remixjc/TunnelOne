GOOD TO KNOW

开始前，
你可能想知道。

现在可以直接安装后日常使用吗？+

v0.3.0 已采用 System Extension 架构，发布流水线支持签名、Apple 公证和通用架构 DMG。请选择 signed 安装包，并在系统设置允许网络扩展。当前仍为 Beta，真实联网、休眠恢复和多用户验收结果见项目测试清单；preview 包用于开发，不能代替签名版本。

可以使用其他代理客户端吗？+

可以使用提供标准 macOS 系统代理的客户端，包括 Clash Verge、Clash Party 等。代理服务需要已运行，TunnelOne 不启动指定软件。仅 TUN、WPAD 或额外认证代理需单独验证。

“带入代理”会代理所有应用吗？+

它通过隧道的 HTTP、HTTPS、SOCKS 或 PAC 系统代理设置工作，影响遵循系统代理的应用。忽略系统代理的程序、UDP 和游戏流量不在这一开关的保证范围内；WireGuard 路由仍由 AllowedIPs 决定。

我的私钥和节点配置在哪里？+

WireGuard 私钥由系统钥匙串存储。代理 YAML 保存在本机 App Group 容器内，仅本地应用和扩展使用。项目没有账户或遥测服务。请将导出的隧道配置和代理 YAML 视作敏感数据。

已经发布的原型等同于客户端吗？+

原型用于体验设计方向，全部连接与数据都是模拟。实际客户端采用 AppKit 与本地 WebKit 界面；当前实现范围、开发限制和验收清单以仓库文档为准。
